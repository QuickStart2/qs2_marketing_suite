# qs2_marketing_suite
Odoo 19 Marketing Suite: Track every euro from ad click to revenue. Media plans, ad creatives, lead webhooks, web tracking, scoring and WhatsApp messaging.

# QS2 Marketing Suite for Odoo 19 Community

> Dal click dell'inserzione al fatturato generato: suite di moduli Odoo 19 CE per la gestione completa del marketing: pianificazione media, tracciamento lead, inserzioni pubblicitarie, reportistica e messaggistica WhatsApp.

---

## Moduli

| Modulo | Sommario |
|--------|----------|
| **qs2_marketing_suite_base** | Brand, Agenzie, Piani Media con metriche automatiche (CPL, CPC, CPA, ROAS), Inserzioni con Kanban e campi marketing sul CRM |
| **qs2_lead_webhook** | Endpoint webhook per creare lead, task e candidature HR da form esterni (Make, Typeform, Google Sheets) |
| **qs2_web_tracking** | Codice tracking univoco per contatti e tracciamento visite web con `?track=CODE` |
| **qs2_marketing_reports** | 3 report SQL preconfigurati: qualità lead, marketing/budget e vendite/fatturato |
| **qs2_whatsapp_bridge** | Invio e ricezione messaggi WhatsApp via QR code con interfaccia chat integrata |
